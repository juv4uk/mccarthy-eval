# Довідник функцій — просто українською

Цей файл відповідає на просте питання: **що кожна реалізована функція
реально робить**, без формул і цитат сторінок. Якщо потрібне
провенанс-обґрунтування (точна сторінка маніфесту, чому саме так
реалізовано, які знахідки й самокорекції були по дорозі) — дивись
`docs/HISTORICAL-FUNCTION-LEDGER.md` і `tests/*/PROVENANCE.md` у
відповідних корпусах. Цей файл — лише пояснення поведінки, простою
мовою.

## Ядро Маккарті 1960 (сім примітивів + іменована рекурсія)

| Функція | Що робить |
|---|---|
| `QUOTE` | Повертає свій аргумент без обчислення — буквально "не чіпай це". |
| `ATOM` | Перевіряє, чи є значення атомом (символом/числом), а не парою (списком) — `T`/`NIL`. |
| `EQ` | Перевіряє тотожність двох атомів (те саме значення на "нижньому рівні", не структурну рівність). |
| `COND` | Розгалуження: перебирає пари `(умова . дія)`, виконує дію першої істинної умови. |
| `CAR` | Повертає перший елемент пари (голову списку). |
| `CDR` | Повертає другу частину пари (хвіст списку). |
| `CONS` | Будує нову пару з двох значень — основна "цеглинка" всіх структур даних. |
| `LABEL` | Дає функції ім'я, щоб вона могла викликати сама себе (іменована рекурсія). |
| `LAMBDA` | Визначає функцію: список параметрів + тіло. |
| `DEFINE` | Зберігає функцію під іменем у глобальному середовищі (щоб можна було викликати за назвою в наступних формах). |

## Історична арифметика (LISP 1.5, §4.2)

| Функція | Що робить |
|---|---|
| `PLUS` | Сума довільної кількості чисел (не лише двох). |
| `TIMES` | Добуток довільної кількості чисел. |
| `DIFFERENCE` | Різниця двох чисел. |
| `ZEROP` | Перевіряє, чи число дорівнює нулю. |

## Appendix A — прості asm-примітиви

| Функція | Що робить |
|---|---|
| `NULL` | Перевіряє, чи значення — порожній список (`NIL`). |
| `EQUAL` | Структурна рівність — рекурсивно порівнює цілі списки, не лише атоми (на відміну від `EQ`). |
| `LIST` | Будує список із довільної кількості аргументів. |
| `AND` | Логічне "і" з коротким замиканням (зупиняється на першому хибному). |
| `OR` | Логічне "або" з коротким замиканням (зупиняється на першому істинному). |
| `NOT` | Логічне заперечення. |
| `RPLACA` | **Мутує** пару на місці: підміняє її перший елемент (без створення нової пари). |
| `RPLACD` | Те саме, але підміняє другий елемент (хвіст). |

## Appendix A — арифметика й предикати

| Функція | Що робить |
|---|---|

| `ADD1` / `SUB1` | Додає / віднімає 1. |
| `MAX` / `MIN` | Найбільше / найменше з аргументів. |
| `RECIP` | Обернене число (1/x). |

| `DIVIDE` | Повертає одразу пару (частка . остача). |

| `ONEP` / `MINUSP` | Дорівнює 1? / від'ємне? |
| `NUMBERP` / `FIXP` / `FLOATP` | Чи є число / чи ціле / чи дробове (у нас завжди "ні", бо дробових немає). |
| `LOGOR` / `LOGAND` / `LOGXOR` | Побітові АБО / І / виключне АБО. |

## Appendix A — бібліотечні функції (звичайний Lisp-код через LABEL/LAMBDA)

| Функція | Що робить |
|---|---|
| `SUBST` | Підставляє значення замість усіх входжень структурно рівного фрагмента в дереві. |
| `MEMBER` | Перевіряє, чи є елемент у списку. |
| `APPEND` | Склеює два списки в один. |
| `MAPLIST` | Застосовує функцію до кожного **хвоста** списку (не до елемента!) і збирає результати. |
| `PAIR` | Зшиває два списки в список пар "елемент-до-елемента" (як alist). |
| `SASSOC` | Пошук пари за ключем у alist, з функцією-заглушкою на випадок "не знайдено". |
| `SEARCH` | Пошук елемента за довільним предикатом, з окремими функціями "знайшов"/"не знайшов". |
| `REVERSE` | Розвертає список. |
| `LENGTH` | Довжина списку (лише верхній рівень). |
| `COPY` | Глибоко копіює структуру. |
| `SUBLIS` | Масова підстановка за списком пар (ключ . значення) по всьому дереву. |

## Appendix B — замикання (closures)

| Функція | Що робить |
|---|---|
| `FUNCTION` | Загортає функцію разом із **поточним оточенням** — щоб вона "запам'ятала" змінні з місця свого створення. |
| `FUNARG` | Внутрішнє представлення "загорнутої" функції (сама трійка, яку створює `FUNCTION`) — не викликається напряму користувачем. |

Без `FUNCTION` функція, повернута як значення, "забуває" свої змінні —
це справжня історична межа 1962 року, не наш недогляд.

## Appendix B — program feature (Algol-подібні програми всередині Lisp)

| Функція | Що робить |
|---|---|
| `PROG` | Оголошує "програму" зі своїми локальними змінними й послідовністю операторів (як `begin...end`). |
| `SETQ` | Змінює значення вже існуючої змінної (не створює нову). |
| `SET` | Те саме, але сам обчислює, яку саме змінну міняти (замість буквального імені). |
| `GO` | Безумовний перехід на мітку всередині `PROG`. |
| `RETURN` | Достроково завершує `PROG` із заданим значенням. |

## Property lists (властивості символів)

| Функція | Що робить |
|---|---|
| `GET` | Читає властивість символу за її "індикатором" (ключем). |
| `DEFLIST` | Масово встановлює одну властивість для списку пар (символ . значення). |
| `REMPROP` | Видаляє властивість (ключ+значення) із символу. |
| `FLAG` | Ставить "прапорець" (властивість без значення) на список символів. |
| `REMFLAG` | Знімає прапорець. |

## Масиви

| Функція | Що робить |
|---|---|
| `ARRAY` | Оголошує один або кілька масивів (з розмірами) — після цього кожна назва масиву сама стає функцією. |
| `alpha[i;j]` (виклик масиву) | Читає елемент за координатами. |
| `alpha[SET;x;i;j]` (виклик масиву) | Записує `x` в цю позицію. |
